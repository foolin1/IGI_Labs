# Лабораторные работы по курсу IGI

Этот репозиторий содержит лабораторные работы, выполненные в рамках курса по информатике и геоинформационным системам (IGI). Задания делятся на два блока:

- 🐍 **Python-скрипты** — аналитика, алгоритмы, работа с файлами и т.д.
- 🌐 **Django веб-приложение** — проект веб-сайта с использованием фреймворка Django. Усовершенствование сайта с использованием CSS и JS.
